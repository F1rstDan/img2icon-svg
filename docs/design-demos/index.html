设计方向对比 · 单色图标转 SVG 工具

下面 3 个方向都围绕同一套信息架构「导入 → 预处理 → 矢量化 → 导出」，区别在于视觉语法、布局重心与交互节奏。先看 Demo 再决定要把真实项目往哪个方向迭代。

方向 A · Kenya Hara 式东方极简

高端 / 留白 / 低噪声

目标是把工具做得更像「纸面编辑台」：浅底、秩序感、把重点留给图像与结果；操作区更克制、层级更清晰。
