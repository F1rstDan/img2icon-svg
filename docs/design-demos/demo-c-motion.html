方向说明（落地时的布局优化要点）

  • 把“过程”可视化：处理中状态、进度、节点规模聚合在顶部一处，形成节奏锚点。
  • 动效策略：只在“导入/参数变化 → 新结果出现”这一个时刻动，让用户把动效等同于反馈。
  • 控件策略：面板保持克制，避免满屏微交互；需要时可提供“关闭动效”。
  • 适合：需要更强“工具质感/沉浸感”的场景；不适合对比度敏感或偏打印/浅色风格的用户。
